## 🌌 Architectural Overview

Mainstream transformer models operate within rigid, flat, discrete token-by-token coordinate sequence grids ($N \times N$). When temperature ($\mathcal{T}$) updates are applied, they act as sudden, ungrounded global scalar modifications. This creates severe structural deficits, rank collapse, and the classic vanishing gradient bottleneck.

The **Arcan Family Architecture** resolves this by mapping the model's thermodynamic state continuously around a compact $360^\circ$ ($\tau = 2\pi$) space. The token decoding trajectory is transformed from a series of disjointed arithmetic updates into a smooth, conservative orbital flight path.
